1. โครงสร้างไฟล์ HTML
เว็บหน้านึงประกอบด้วยอะไรบ้าง?

ไฟล์ .html ทุกไฟล์มีโครงสร้างหลัก 3 ส่วนเสมอ:

<!DOCTYPE html> <!-- บอก Browser ว่านี่คือ HTML5 (มาตรฐานล่าสุด) --> <html lang="th"> <!-- ห่อทุกอย่างไว้ lang="th" = บอกว่าเนื้อหาเป็นภาษาไทย --> <head> <!-- ส่วน "ความลับ" — ผู้ใช้ไม่เห็น แต่ Browser อ่าน --> <meta charset="UTF-8"/> <!-- รองรับภาษาไทย / อักขระพิเศษ --> <meta name="viewport" content="width=device-width, initial-scale=1.0"/> <!-- ทำให้เว็บดูดีบนมือถือ --> <title>ALL POWER Group Dashboard</title> <!-- ชื่อที่แสดงบน Tab ของ Browser --> <link href="...Google Fonts..." rel="stylesheet"/> <!-- โหลดฟ้อนต์ Sarabun จาก Google --> <style> ... CSS อยู่ตรงนี้ ... </style> </head> <body> <!-- ส่วนที่ผู้ใช้เห็น — ใส่ div, table, button ฯลฯ ตรงนี้ --> <script> ... JavaScript อยู่ตรงนี้ (ท้ายสุดเสมอ) ... </script> </body> </html>
💡
ทำไม <script> ถึงอยู่ล่างสุด? เพราะ JS ต้องรอให้ HTML โหลดก่อน ถ้าใส่ไว้ข้างบน JS จะหา div ไม่เจอและพัง
HTML Tags ที่ใช้ในเว็บนี้
Tagใช้ทำอะไรตัวอย่างในเว็บนี้
<div> กล่องสารพัดประโยชน์ ใช้จัดกลุ่ม element class="panel", class="metric"
<span> กล่องเล็กๆ อยู่ในบรรทัด ใช้ตกแต่งข้อความ class="badge", class="dim"
<table> <thead> <tbody> <tfoot> ตาราง — head = หัวตาราง, body = ข้อมูล, foot = แถวรวม ตารางรายการ SO ทั้งหมด
<tr> <th> <td> tr = แถว, th = ช่องหัว (bold), td = ช่องข้อมูล แต่ละแถวใน renderTable()
<button> ปุ่มกด — ต้องมี event listener จึงจะทำงาน ปุ่ม "เพิ่มรายการ", "บันทึก", "ลบ"
<input> ช่องกรอกข้อมูล — type กำหนดชนิด type="text", type="number", type="checkbox"
<select> <option> Dropdown เลือกตัวเลือก ฟิลเตอร์ Sales Co., ฟิลเตอร์สถานะ
<a> Link — href คือปลายทาง ปุ่ม "จัดการข้อมูล" ลิงก์ไป admin.html

2. CSS — ตกแต่งหน้าตา
CSS คือภาษาที่บอกว่าแต่ละ element ควรหน้าตาเป็นยังไง
2.1 ตัวแปรสี — :root { }

แทนที่จะพิมพ์ #1b3a5c ซ้ำๆ ทุกที่ เราเก็บไว้ในตัวแปรครั้งเดียว แล้วเรียกใช้ผ่าน var(--ชื่อ)

:root { /* ประกาศตัวแปร CSS — ขึ้นต้นด้วย -- เสมอ */ --navy: #1b3a5c; /* สีน้ำเงินเข้ม ใช้เป็น Header */ --blue: #2563a8; /* สีน้ำเงินกลาง */ --red: #c0392b; /* สีแดง ใช้กับค่า Warning */ --radius: 10px; /* ความมนของมุมกล่อง */ --shadow: 0 2px 12px rgba(27,58,92,0.09); /* เงาอ่อนๆ */ } /* วิธีเรียกใช้ */ .metric { background: var(--white); /* แทนที่จะพิมพ์ #ffffff */ border-radius: var(--radius); /* แทนที่จะพิมพ์ 10px */ box-shadow: var(--shadow); /* เงา */ }
✅
ข้อดีของตัวแปร CSS: ถ้าอยากเปลี่ยนสีธีมทั้งเว็บ แค่แก้ใน :root ที่เดียว ทุกที่อัปเดตพร้อมกัน!
2.2 Layout — Flexbox & Grid

Flexbox — จัดของให้เรียงแนวนอนหรือแนวตั้ง

.page-header { display: flex; /* เปิด Flexbox */ align-items: center; /* จัดกึ่งกลางแนวตั้ง */ gap: 16px; /* ระยะห่างระหว่าง item */ } .btn-admin { margin-left: auto; /* ดันปุ่มไปชิดขวาสุด */ }

CSS Grid — แบ่งพื้นที่เป็นตารางอัตโนมัติ ใช้กับ KPI Cards

.summary-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); /* auto-fill = สร้างคอลัมน์ให้เต็มพื้นที่ */ /* minmax(200px, 1fr) = แต่ละช่องกว้างอย่างน้อย 200px */ /* ผล: หน้าจอใหญ่ = 4 การ์ด, หน้าจอเล็ก = 2-3 การ์ด */ gap: 16px; /* ระยะห่างระหว่างการ์ด */ }
2.3 Animation & Transition — ความลื่นไหล

Transition — ทำให้การเปลี่ยนแปลงสมูท เช่น hover

.metric { transition: transform 0.15s, box-shadow 0.15s; /* เมื่อ transform หรือ box-shadow เปลี่ยน ให้ค่อยๆ เปลี่ยน 0.15 วินาที */ } .metric:hover { transform: translateY(-2px); /* ลอยขึ้น 2px เมื่อ hover */ box-shadow: var(--shadow-lg); /* เงาเข้มขึ้น */ }

@keyframes + animation — สร้างการเคลื่อนไหวต่อเนื่อง เช่น Loading Spinner

@keyframes spin { to { transform: rotate(360deg); } /* "to" คือ จาก 0° หมุนไป 360° (1 รอบ) */ } .spinner { animation: spin 0.8s linear infinite; /* spin = ชื่อ keyframe | 0.8s = ความเร็ว | infinite = วนไม่หยุด */ }

Toast (admin.html) — กล่องแจ้งเตือนที่เลื่อนขึ้นมา

#toast { transform: translateY(80px); /* ซ่อนไว้ใต้หน้าจอ */ opacity: 0; /* โปร่งใส (มองไม่เห็น) */ transition: all 0.3s; } #toast.show { transform: translateY(0); /* เลื่อนขึ้นมาที่ตำแหน่งปกติ */ opacity: 1; /* มองเห็นได้ */ }
2.4 Responsive — @media

ทำให้หน้าเว็บแสดงผลต่างกันตามขนาดหน้าจอ

@media (max-width: 768px) { /* CSS ข้างในนี้จะทำงานเฉพาะเมื่อหน้าจอ ≤ 768px (มือถือ/แท็บเล็ต) */ body { padding: 0.8rem; font-size: 14px; } .toolbar input#searchInput { width: 100%; } /* ช่องค้นหาเต็มความกว้าง */ }

3. JavaScript — การทำงานของโค้ด
JS ทำให้เว็บ "มีชีวิต" — กดปุ่ม, โหลดข้อมูล, คำนวณ, แสดงผล
3.1 ตัวแปร (Variables) — เก็บข้อมูล
/* ===== STATE ใน index.html ===== */ let raw = []; // Array เก็บข้อมูลทุก SO ที่ดึงมาจาก Supabase let sortCol = 'depositVal'; // คอลัมน์ที่กำลัง sort อยู่ let sortDir = -1; // ทิศทาง: 1 = น้อย→มาก, -1 = มาก→น้อย const hiddenCols = new Set(['costPrice', 'remark']); // คอลัมน์ที่ซ่อนอยู่ let selectedRows = new Set(); // id ของแถวที่ถูกเช็คเลือก let searchTags = []; // คำค้นหาที่เพิ่มเป็น Tag แล้ว
คำสั่งความต่าง
const ค่าคงที่ — กำหนดครั้งเดียว เปลี่ยนไม่ได้ เช่น URL, API Key
let ตัวแปร — เปลี่ยนค่าได้ตลอด เช่น sortCol, sortDir
new Set() เหมือน Array แต่ไม่มีค่าซ้ำ เหมาะเก็บ id ที่เลือกไว้
3.2 ฟังก์ชัน (Functions) — ชุดคำสั่ง

ฟังก์ชันคือกลุ่มคำสั่งที่ตั้งชื่อไว้ เรียกใช้ซ้ำได้ทุกเมื่อ

/* แบบปกติ */ function showLoading(v) { // v คือ parameter (ค่าที่รับเข้ามา) — true = แสดง, false = ซ่อน document.getElementById('loadingOverlay').classList.toggle('hidden', !v); } /* Arrow Function — เขียนสั้นกว่า */ const api = (path, opts = {}) => fetch(`...`, opts); // (path, opts) = รับค่า 2 ตัว, opts = {} คือค่า default ถ้าไม่ส่งมา /* ฟังก์ชัน Async — ต้องรอผล API */ async function loadData() { const res = await api('orders?select=*'); // await = หยุดรอจนกว่า API จะตอบกลับ }
📌
ฟังก์ชันหลักในเว็บนี้:
loadData() — ดึงข้อมูลจาก Supabase
computeFields() — คำนวณ Amount, กำไร, ตปท.
renderSummary() — วาด KPI Cards
renderTable() — วาดตาราง (เรียกทุกครั้งที่ filter/sort เปลี่ยน)
getStatus(r) — คืนสถานะของแต่ละ SO
3.3 Array Methods — จัดการข้อมูลชุด

เมธอดเหล่านี้ใช้บ่อยมากในการจัดการข้อมูล

เมธอดทำอะไรใช้ที่ไหนในเว็บ
.map(r => ...) แปลงทุก item ในอาเรย์ คืนอาเรย์ใหม่ที่แปลงแล้ว raw = data.map(r => ({id: r.id, so: r.so, ...}))
แปลง JSON จาก API เป็นรูปแบบที่เราต้องการ
.filter(r => ...) คัดกรองเฉพาะ item ที่ผ่านเงื่อนไข raw.filter(r => getStatus(r) === fSt)
กรองตาม filter สถานะ
.reduce((s, r) => s + r.amt, 0) รวมค่าทั้งหมด (เหมือน SUM ใน Excel)
s = ผลสะสม, r = ค่าปัจจุบัน, 0 = ค่าเริ่มต้น		 filtered.reduce((s, r) => s + (r.saleAmt || 0), 0)
รวม Amount ทั้งหมด
.forEach(item => ...) วนซ้ำทุก item แต่ไม่คืนค่า raw.forEach(r => { r.saleAmt = r.salePrice * r.order })
คำนวณ saleAmt ทุก SO
.sort((a, b) => ...) เรียงลำดับ — คืนค่า <0, 0, >0 Sort คอลัมน์เมื่อกดหัวตาราง
.find(x => x.id === id) หาค่าตัวแรกที่ตรงเงื่อนไข คืน item นั้น allData.find(x => x.id === id)
หาข้อมูล SO ที่ต้องการแก้ไข
.every(r => ...) ตรวจว่าทุก item ตรงเงื่อนไขหรือไม่ filtered.every(r => r.costAmt == null)
ตรวจว่าทุกแถวไม่มีต้นทุน
.join('') รวม Array of strings เป็น string เดียว filtered.map(r => `<tr>...</tr>`).join('')
รวม HTML แถวทั้งหมดเป็นก้อนเดียว
.includes(t) ตรวจว่ามีค่านี้ใน Array หรือไม่ searchTags.includes(v.toLowerCase())
ไม่ให้ค้นหา tag ซ้ำ
.splice(i, 1) ลบ item ออกจากตำแหน่ง i searchTags.splice(+x.dataset.i, 1)
ลบ tag ออกเมื่อกด ✕
.push(item) เพิ่ม item ต่อท้าย Array searchTags.push(v.toLowerCase())
เพิ่ม tag ค้นหาใหม่
3.4 DOM — ควบคุม HTML ด้วย JavaScript

DOM (Document Object Model) คือการมองหน้าเว็บเป็น Object ที่ JS ควบคุมได้

/* หา element เดี่ยวด้วย id */ const el = document.getElementById('searchInput'); /* → หากล่อง input ที่มี id="searchInput" */ /* หา element หลายอันด้วย CSS selector */ document.querySelectorAll('.row-check').forEach(cb => { // ทำอะไรกับ checkbox ทุกอัน }); /* เปลี่ยนเนื้อหา HTML ข้างใน */ document.getElementById('tableBody').innerHTML = `<tr>...</tr>`; // innerHTML รองรับ HTML tags เช่น <span> /* เปลี่ยนข้อความธรรมดา (ไม่แปลง HTML tag) */ document.getElementById('selCount').textContent = selData.length; /* จัดการ class */ el.classList.add('hidden'); // เพิ่ม class el.classList.remove('hidden'); // ลบ class el.classList.toggle('hidden', !v); // เพิ่มถ้า !v=true, ลบถ้า !v=false el.classList.has('hidden'); // ตรวจว่ามี class นั้นอยู่ไหม /* อ่านค่า dataset (ค่าใน data-xxx attribute) */ const col = btn.dataset.col; // <button data-col="saleAmt"> → "saleAmt" const id = +cb.dataset.id; // + ข้างหน้าแปลง string เป็น number
3.5 Events — รับมือการกระทำของผู้ใช้
/* กดปุ่ม */ document.getElementById('btnAdd').addEventListener('click', async () => { // ทำงานเมื่อกดปุ่ม btnAdd }); /* พิมพ์ในช่อง input — ทุกครั้งที่พิมพ์ */ searchInput.addEventListener('input', renderTable); // 'input' = เรียก renderTable ทันทีที่ค่าเปลี่ยน /* กด Enter ในช่อง search */ searchInput.addEventListener('keydown', e => { if (e.key === 'Enter') { /* เพิ่ม tag */ } }); /* Checkbox เปลี่ยนสถานะ */ cb.addEventListener('change', () => { if (cb.checked) selectedRows.add(id); else selectedRows.delete(id); }); /* วนลูปหลาย element พร้อมกัน */ ['filterStatus', 'filterSales'].forEach(id => document.getElementById(id).addEventListener('input', renderTable) ); // ทำให้ทั้ง filterStatus และ filterSales เรียก renderTable เมื่อเปลี่ยน
3.6 Async/Await + Try/Catch — ดึงข้อมูลจาก API
async function loadData() { showLoading(true); // แสดง Spinner ก่อน try { // ลองทำ — ถ้าสำเร็จจะวิ่งถึงบรรทัดสุดท้ายใน try const res = await api('orders?select=*&order=id.asc'); // await = หยุดรอ API ตอบก่อน ไม่เดินหน้าต่อ if (!res.ok) throw new Error(`HTTP ${res.status}`); // ถ้า response ไม่ ok (เช่น 404, 500) ให้ throw error const data = await res.json(); // แปลง response เป็น JSON object raw = data.map(r => ({...})); renderTable(); } catch(e) { // ถ้าเกิด error ใดๆ ใน try จะมาที่นี่ showError('โหลดไม่สำเร็จ: ' + e.message); } finally { // ทำงานเสมอ ไม่ว่า try จะสำเร็จหรือ error showLoading(false); // ซ่อน Spinner } }
3.7 Template Literals — สร้าง HTML ใน JavaScript

ใช้ Backtick ` แทน ' เพื่อใส่ตัวแปรใน string ได้

/* แบบเก่า — ไม่สะดวก */ '<tr class="' + selClass + '"><td>' + r.so + '</td></tr>' /* แบบใหม่ Template Literal — อ่านง่ายกว่ามาก */ `<tr class="${selClass}"> <td>${r.so}</td> <td>${r.item}</td> </tr>` // ${...} = ใส่ค่าตัวแปรหรือ expression ข้างใน /* Conditional ใน Template Literal */ `${r.profit > 0 ? fmtMoney(r.profit) + ' ฿' : '<span class="dim">-</span>'}` // ? : คือ Ternary Operator — ถ้าเงื่อนไขจริง ? ทำนี่ : ไม่งั้นทำนี่
🧩
Spread Operator ...
[...searchTags, ...(q ? [q] : [])]
... คือ "กระจาย" สมาชิกของอาเรย์ออกมา — รวม searchTags กับ q (ถ้ามี) เป็นอาเรย์เดียว

{...allData[idx], ...data}
ใช้กับ Object — รวมข้อมูลเก่ากับข้อมูลใหม่ ค่าใหม่ทับค่าเก่าถ้าชื่อซ้ำกัน

HTTP Methodใช้ทำอะไรใช้ที่ไหน
GET (default) ดึงข้อมูล api('orders?select=*&order=id.asc') — โหลดทุก SO
POST สร้างข้อมูลใหม่ api('orders', { method:'POST', body: JSON.stringify(data) }) — เพิ่ม SO
PATCH แก้ไขข้อมูลบางส่วน api('orders?id=eq.5', { method:'PATCH', body: ... }) — แก้ SO id=5
DELETE ลบข้อมูล api('orders?id=eq.5', { method:'DELETE' }) — ลบ SO id=5

function computeFields() { raw.forEach(r => { r.saleAmt = r.salePrice * r.order; // Amount = ราคา × จำนวน r.depositVal = r.salePrice * r.deposit; // มูลค่ารอ INV. = ราคา × รอ INV. r.remain = Math.max(r.order - r.deposit - r.inv, 0); // ตปท. = คำสั่ง - รอ INV. - INV.แล้ว (ไม่ติดลบ) r.costAmt = r.costPrice != null ? r.costPrice * r.order : null; r.profit = r.costAmt != null ? r.saleAmt - r.costAmt : null; }); }
getStatus() — ตัดสินสถานะแต่ละ SO
function getStatus(r) { if (r.stored > 1) return 'stored_many'; // ฝากของ > 1 → สีเหลือง if (r.stored > 0) return 'ready'; // ฝากของ 1 → พร้อมส่งปกติ if (r.deposit === 0 && r.remain > 0) return 'abroad'; // ยังสั่งตปท.อยู่ if (r.deposit > 0) return 'ready'; // รอ INV. → พร้อมส่ง return 'partial'; // ไม่ตรงเงื่อนไขใดเลย } // JavaScript อ่าน if จากบนลงล่าง ถ้าตรงข้อแรก return ทันที ไม่เช็คข้อถัดไป

function renderTable() { // 1. อ่านค่า filter ปัจจุบัน const q = document.getElementById('searchInput').value.trim().toLowerCase(); const fSt = document.getElementById('filterStatus').value; const fSales = document.getElementById('filterSales').value; // 2. กรองข้อมูล let filtered = raw.filter(r => { const allTags = [...searchTags, ...(q ? [q] : [])]; // รวม tag + คำที่กำลังพิมพ์ const matchSearch = allTags.every(t => // ต้องตรงทุก tag r.so.toLowerCase().includes(t) || r.item.toLowerCase().includes(t)); const matchStatus = !fSt || getStatus(r) === fSt; // !fSt = ไม่ได้เลือก filter const matchSales = !fSales || r.salesco === fSales; return matchSearch && matchStatus && matchSales; // ต้องผ่านทุกเงื่อนไข }); // 3. Sort filtered.sort((a, b) => { let va = a[sortCol], vb = b[sortCol]; // va, vb = ค่าของคอลัมน์ที่ sort if (typeof va === 'string') return va.localeCompare(vb, 'th') * sortDir; return (va - vb) * sortDir; // sortDir = 1 (น้อย→มาก), -1 (มาก→น้อย) }); // 4. สร้าง HTML แถวทั้งหมดแล้วใส่ใน tableBody document.getElementById('tableBody').innerHTML = filtered.map((r, i) => { // สร้าง HTML string ของแต่ละแถว return `<tr data-id="${r.id}">...</tr>`; }).join(''); // รวมทุกแถวเป็น string เดียว }
fmt() และ fmtMoney() — ฟังก์ชันจัดรูปแบบตัวเลข
function fmt(n) { return (n != null && n !== 0) ? n.toLocaleString('th-TH') : '-'; // toLocaleString('th-TH') = 1000 → "1,000" แบบไทย // ถ้าค่าเป็น 0 หรือ null คืน '-' แทน } function fmtMoney(n) { if (n == null || n === 0) return '<span class="dim">-</span>'; return n.toLocaleString('th-TH', { minimumFractionDigits:2, maximumFractionDigits:2 }); // 1500.5 → "1,500.50" มีทศนิยม 2 ตำแหน่งเสมอ }

7. สรุปภาพรวม — ข้อมูลไหลยังไง?
ทุกอย่างเชื่อมกันอย่างไร
ผู้ใช้ทำJS เรียกผลที่เกิด
เปิดหน้า index.html loadData() → computeFields() → renderSummary() + renderTable() ดึงข้อมูลจาก Supabase แล้ววาดทุกอย่าง
พิมพ์ในช่องค้นหา renderTable() วาดตารางใหม่ กรองเฉพาะที่ตรง
กดหัวคอลัมน์ เปลี่ยน sortCol/sortDir → renderTable() เรียงลำดับตามคอลัมน์นั้น
เช็ค Checkbox แถว เพิ่ม id เข้า selectedRows → updateSelectedFooter() แถวเปลี่ยนสีฟ้า Footer ล่างแสดงยอดรวม
กดปุ่ม ซ่อน คอลัมน์ เพิ่ม/ลบออกจาก hiddenCols → renderTable() คอลัมน์หาย/กลับมา
เปิด admin.html แล้ว Login unlockAdmin() → loadData() บันทึก session, โหลดข้อมูล
กดปุ่ม "เพิ่มรายการ" readForm() → api(POST) → renderTable() ส่งข้อมูลไป Supabase, อัปเดตตารางทันที
กดปุ่ม "แก้ไข" openEdit(id) → แสดง Modal เปิดหน้าต่างแก้ไข
กด "บันทึก" ใน Modal api(PATCH) → closeModal() → renderTable() บันทึกลง Supabase, ปิด Modal, อัปเดตตาราง
กด 🗑️ ลบ confirmDelete() → แสดง Dialog ยืนยัน รอให้กด "ลบเลย" ก่อนถึงจะลบจริง
